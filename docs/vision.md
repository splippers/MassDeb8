# Project vision & tone

MassDeb8 is a LAN-hosted debating arena where:

- Debater nodes are **Ollama-backed LLMs** running historical personas.
- A central **Arena server** orchestrates turns, pacing, and transcripts.
- A human **Chair** moderates via a web UI—half serious referee, half Monty Python sketch director.
- Hybrid tone: real philosophical content, with absurd interruptions, pacing gags, and Confucius one-liners.

## Design pillars

- **Local-first**: everything runs on your LAN; each debater can be on a different box.
- **Performative, not just evaluative**: this is theatre, not a benchmark.
- **Hybrid seriousness**: arguments can be deep, but the framing is playful.
- **Slow is a feature**: “Ent Mode” makes latency feel intentional and funny.
